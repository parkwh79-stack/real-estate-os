REALYTICS brand assets
======================

Drop the two brand images here with EXACTLY these filenames so the web app
shows them automatically:

  realytics-logo.png   — the REALYTICS × WAN2 logo (skyline + arrow). Shown in the sidebar brand area.
  realytics-hero.png   — the "powered by WAN2" character/avatar image. Shown in the home page hero banner.

Recommended: PNG with transparent or light background.
- logo  ~ 600×200 (wide)
- hero  ~ 760×600

These are referenced as /brand/realytics-logo.png and /brand/realytics-hero.png
in components/layout/sidebar.tsx and app/page.tsx. Until the files are added,
the UI shows the image alt text / falls back gracefully.
